快门速度通常指曝光持续时间：1/250 秒比 1/60 秒短。它决定收集光线期间，运动如何在画面中铺开。

**简短回答：**先根据想要的运动效果选择时间，再处理其他曝光取舍。没有一个快门速度能保证所有运动主体都清晰。

## “照片模糊”的四种原因

| 原因         | 画面线索                             | 可尝试的方法                     |
| ------------ | ------------------------------------ | -------------------------------- |
| 主体运动     | 移动区域拖影，静止区域可能清晰       | 缩短时间、把握时机或有意追随拍摄 |
| 相机抖动     | 画面大部出现方向性涂抹               | 支撑、防抖、缩短时间、改善握持   |
| 对焦错误     | 其他平面更清晰，或全画面没有准确合焦 | 检查对焦模式、对焦点、光圈和距离 |
| 滚动快门变形 | 直线运动物体倾斜，或出现灯光条带     | 选择合适快门模式与机型设置       |

图像防抖能补偿某些**相机运动**，不能凝固奔跑的儿童或鸟翅膀。

## 运动要相对于画面判断

横穿画面的人与朝你走来的人，模糊方式可能不同。同一主体在宽广画面中每秒跨过的像素，通常少于紧凑取景。追随拍摄能让运动主体相对稳定、背景形成拖影，但需要练习。

## 示例设置

使用 **1/30 秒**有意追随拍摄，可能让骑车人相对清晰、背景模糊。**1/500 秒**可能让骑手和背景都更接近凝固。这些只是示例设置，不是保证；速度、方向、取景、对焦与技术都影响结果。

从 1/125 秒改为 1/250 秒，曝光时间减半，即减少一档。若用 ISO 补偿，入射光并未增加，改变的是输出链路；若用光圈补偿，景深也可能改变。

## 机械快门与电子快门

电子快门可以安静、快速，但某些传感器会先后读取不同行，运动物体可能倾斜或变形，人工光源也可能产生条带。屏幕上很快的快门数值，不一定意味着整块传感器同时采样。请查说明书了解闪光、频闪抑制和读出限制。

## 常见误区

- **焦距倒数法则保证手持清晰。**它只是粗略历史经验，无法跨分辨率、防抖和主体运动给出保证。
- **防抖档位越多，任何主体都清晰。**防抖处理某些相机运动，不处理对焦和主体运动。
- **背景模糊就证明景深浅。**运动造成的背景拖影看似相似，原因却不同。

## 练习：一个运动主体，三次拍摄

在安全位置拍摄运动规律可预测的主体，使用 1/30、1/125、1/500 秒示例时间，保持取景和对焦方法一致。比较主体清晰度与运动拖影，再在较慢时间尝试平稳追随。记录真实结果，不要把数值当作及格线。
