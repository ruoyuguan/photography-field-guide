新相机有几十个选项，很容易让人想找一组“最佳参数”。但这个问题遗漏了主体、光线和你想要的画面。

**简短回答：**摄影是有意识地记录一段时间内的光。更有用的问题不是“哪个数字最好”，而是“哪些内容应该清晰、明亮、进入画面或得到强调？”

## 一帧画面的四个基本决定

| 决定 | 可以问自己的问题           | 对应的相机环节           |
| ---- | -------------------------- | ------------------------ |
| 光线 | 有多少光到达传感器？       | 光圈与快门时间           |
| 时间 | 运动应该凝固还是拖出模糊？ | 快门速度                 |
| 取景 | 哪些内容应该进入画面？     | 机位、焦距、传感器       |
| 呈现 | 捕获的信号怎样变成图像？   | ISO、RAW 显影、JPEG 处理 |

对焦是另一项独立选择，高速快门不保证对焦正确。构图也不是更昂贵的相机能替你完成的公式。

## 示例：阴影中行走的人

假设示例设置是 **50 mm、F4、1/125 秒、ISO 400**。它只是一个起点，不是通用建议。行走动作可能基本凝固，但经过的自行车仍可能模糊。光圈影响可接受清晰范围；ISO 影响输出映射，并不增加进入相机的光子。

如果画面太暗，先决定能接受哪种取舍：更长的曝光时间、更大的可用光圈，或更亮的输出呈现。如果人物发虚是因为自动对焦偏了，提高 ISO 并不能解决。

## 最有用的习惯：一次只改一件事

拍一张，只改一个控制项，再作比较。保持机位和主体不变，观察亮度之外的变化：背景呈现、运动、噪点还是取景？受控比较比背“晴天参数口诀”更有帮助。

## 常见误区

- **好相机会自动拍出好照片。**器材能扩展选择，但不会替你选择主体和时机。
- **只有一个正确曝光。**同一场景可以有多种合理呈现。应检查重要高光和阴影，而不是把测光读数当成裁决。
- **只有手动模式才专业。**理解相机会替你改变什么之后，半自动模式也可以是有意识的选择。

## 练习：同一场景，三个意图

在窗边拍摄一个静止物体：一张带入房间环境，一张靠近拍摄，一张突出小细节。先改变机位，再考虑换镜头。记录哪个决定最重要。练习指定的是意图，不是固定曝光参数。
