为什么对焦框已经变绿，人物却不清晰，背景反而清楚？对焦确认不保证整张照片都清晰，也不保证相机选择了你想拍的主体。

**简短回答：**自动对焦通过调整镜头来匹配主体距离。对焦模式决定**对焦行为如何随时间变化**，对焦区域决定**相机查看画面中的哪里**。准确对焦、足够景深和没有运动模糊，是三个需要分别满足的条件。

## 三个不同的问题

1. **相机应当何时调整或保持对焦？**这是对焦模式决策：X-T5 上的 AF-S、AF-C 或手动对焦。
2. **相机应当使用画面的哪一部分？**这是对焦区域决策：单点、区域或更广的跟踪范围。
3. **最终照片中哪些内容看起来足够清晰？**这还取决于景深、主体与相机运动、镜头表现和观看尺寸。

不要用更大的光圈数值代替正确的主体选择。更多景深能扩大可接受清晰范围，却不能修复所有对焦错误。

## 随时间变化的对焦行为

| X-T5 对焦模式 | 正常半按快门时的行为                         | 可作为起点的情况                 |
| ------------- | -------------------------------------------- | -------------------------------- |
| **S（AF-S）** | 单次自动对焦在半按期间锁定对焦               | 静止或几乎静止的主体             |
| **C（AF-C）** | 连续自动对焦在半按期间随主体距离变化持续调整 | 朝向或远离相机运动的主体         |
| **M（手动）** | 使用镜头对焦环自行对焦                       | 主动手动控制或自动对焦困难的条件 |

不同厂商的名称和控件会不同。自定义按键、镜头开关以及 Pre-AF 等选项会改变细节行为，因此不能只看字母，还要查看相机显示和说明书。

## 对焦区域：相机应当看哪里？

- **单点：**你选择一个较小区域进行精确放置。适合明确主体；如果点对在背景上，相机也可能准确地对到背景。
- **区域：**一组对焦点让主体在选定范围内有更多活动空间，有助于可预测运动；但区域内其他高反差物体也可能竞争对焦。
- **广域或跟踪：**实际行为取决于 AF-S 还是 AF-C。X-T5 在 AF-S 下提供 Wide、AF-C 下提供 Tracking，它们不是同一种通用算法的两个名字。
- **人脸、人眼或主体识别：**支持该功能的相机上另一项辅助选项。仍需检查识别与区域配置；识别到主体不保证它始终清晰。

## 示例场景

**静态建筑：**AF-S 配合仔细放置的单点是清楚的起点。检查对焦点是否覆盖目标表面，而不是玻璃后的远处物体。

**向你走来的人物：**AF-C 配合适当区域或跟踪范围，让相机有机会更新对焦。仍需足够快门速度控制主体运动，并让有效区域持续包含人物。

**低反差或遮挡：**X-T5 说明书列出了低反差主体、光亮表面、隔着反光材料拍摄，以及对焦框内出现竞争高反差物体等困难情况。可以改变区域或视角、寻找同距离更容易利用的目标，或按需使用放大手动对焦。

## 清晰度诊断不只是 AF 诊断

- **目标主体模糊，另一距离清晰：**检查对焦位置与景深。
- **整幅画面沿一个方向拖影：**考虑相机运动或主体运动，不要只归因于对焦失败。
- **近处和远处细节都模糊：**检查对焦、运动、镜头设置和最终观看条件。
- **对焦反复搜索或跳到其他物体：**重新考虑反差、区域大小、遮挡和对焦行为。

自动对焦不能让行走的人停止运动，高速快门也不能把对焦距离移到人物身上。

## X-T5 操作顺序

1. 把对焦模式选择器设到 **S**、**C** 或 **M**。
2. 使用自动对焦时，选择 **AF/MF 设置 → AF 模式**。
3. 按说明书使用对焦棒选择区域，并调整区域大小。
4. 半按快门时观察有效区域和对焦指示，再以足够放大倍率检查重要照片。

官方说明书指出，启用 **Pre-AF** 后，即使没有半按快门，S 和 C 模式也会持续调整对焦。因此“AF-S 总是等待半按才动作”的笼统规则并不完整。

## 练习：分离时间与区域

先用固定曝光和构图拍摄静止的高反差物体。保持相同单点比较 AF-S 与 AF-C，记录这种控制条件下结果是否不同。

然后请一个人以安全、可重复的速度向你走来。使用 AF-C，让有效区域跟随人物并拍一小组。放大检查目标面部，不只看缩略图。再用不合适、朝向背景的对焦点重复一次，理解区域选择为何重要。

最后尝试低反差静止物体。若自动对焦困难，改变目标或使用手动对焦辅助。记录限制，不把每次失败都归因于使用者。
