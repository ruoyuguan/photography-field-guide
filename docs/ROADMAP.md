## 2. Phase 2A：稳定工程与内容基础

先解决真实基础问题，再增加站点面积。

1. **保存当前基线。** 检查并记录 tracked、deleted 与 untracked 文件；禁止重建模板覆盖定制。若后续需换开发目录，完整保留未提交文件及历史，核对迁移前后状态；不能只克隆远端后丢弃本地工作。
2. **统一运行环境。** 依据当前 lockfile 的实际 engine 要求选择 Node；当前 Astro 7.4.2 要求至少 Node 22.23.4，不能继续笼统写“Node 22+”。统一 README、`packageManager`、`engines`、两个 CI workflow 和可选运行时版本文件；保持依赖锁定，不借此全面升级依赖。
3. **修复文档国际化。** 中文文档的站点标题入口目前跳到英文首页／导览，侧栏分组与搜索部分文案仍是英文。使用当前 Starlight 路由数据接口，对齐语言查找键，实际点击验证对应语言落点。
4. **统一 URL 规则。** 区分部署域名、可选 `base` 和内容路径。普通页面与 Starlight 的 canonical、hreflang、sitemap、robots、社交图片和静态资源必须由同一套部署信息生成。先用本地根路径和模拟项目子路径验证，不因此绑定或发布平台。
5. **迁移学习路由。** 将现有 `start-here` 和 `basics` 内容迁入 `/learn/` 体系，中英文保持相同 slug。更新导航、文内链接、首页入口、侧栏和 smoke；为旧路径选择能在目标静态托管环境工作的兼容方案，未验证前不宣称重定向有效。
6. **增加渐进的数据约束。** 在 `docsSchema` 上扩展文章元数据；为术语、器材、资源、画廊建立最小 schema。先加入少量真实种子数据和跨实体引用检查，再扩大数据量。
7. **保留可复用模板模块。** 不对所有未使用组件做清扫式删除；优先防止商业演示进入公开路由或新集合。删除／替换前追踪调用及内容依赖。
8. **补齐贡献者基础。** 文档说明命令、译文配对、事实核查、链接状态和内容许可边界；贡献指南、Issue／PR 模板可逐步加入，不阻塞首个本地工具。

退出门槛：当前双语内容仍可访问；本轮相关类型、格式、构建和 smoke 全部通过；根路径与模拟子路径中的资源、元数据和语言切换正确；内部引用检查不存在无效引用；没有新增演示页面或虚假功能入口。

## 3. Phase 2B：先完成两个真正可用的工具

### 3.1 画幅系数与等效焦距

输入参考传感器尺寸、目标传感器尺寸和实际焦距，输出对角线画幅系数、等效焦距和有明确轴向标注的视角示意。近似的“APS-C 约 1.5×”与基于具体尺寸的计算分开展示。长宽比不同时，说明对角线等效不保证水平及垂直视角同时一致。

采用原生范围／数字输入、局部 TypeScript 和 SVG；公式独立于界面。显示输入单位、参考画幅、假设及结果解释。非法、空值或不合理输入显示具体错误，不静默归零或输出 `NaN`。正文明确镜头实际焦距不会因传感器变化而改变，同一相机位置下裁切不改变透视关系。

### 3.2 曝光档位

比较前后两组光圈、快门时间和 ISO。分别输出光圈／快门决定的光曝光比例，以及简化模型中的输出亮度比例。不得把 ISO 增加表述为传感器收到更多光子；面积或总光量比较必须声明场景、视角、快门、F 数值与光学透射等比较条件。

以通用参数进行计算；X-T5／XF16–50mm 仅作为经过核实的示例。未获精确证据前，不构造 XF16–50mm 在中间焦距处的最大光圈曲线，也不把通用曝光计算器伪装成真实相机菜单模拟器。

### 3.3 工具退出门槛

| 类别       | 必须通过                                                                                                                              |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| 公式       | APS-C 16mm 约 24mm 等效；不同尺寸 crop factor；F2.8→F4 约减少 1 档；快门时间加倍增加 1 档；ISO 改变不改变固定光圈／快门下的入射光模型 |
| 精度与假设 | 近似值与真实尺寸计算分开；单位一致；定义参考画幅、轴向、模型条件与适用范围                                                            |
| 边界       | 空输入、零、负数、非有限数值、非法尺寸、极端值；合法边界不崩溃，非法值不输出误导性结果                                                |
| 同步       | 滑块与数字输入双向一致；重置恢复可解释的默认状态；多工具实例不相互污染                                                                |
| 双语       | 标签、说明、单位提示、错误与结果真正双语；切换优先对应工具页                                                                          |
| 无障碍     | 原生键盘可用、焦点可见、标签关联、文本结果可读、信息不只靠颜色；减少动画偏好有效                                                      |
| 回退       | 无 JavaScript 时有公式、示例或静态说明，不能呈现看似仍在工作的失效控件                                                                |
| 响应式     | 手机触控和窄视口可用，表单／SVG／结果无横向溢出；桌面与平板同样可读                                                                   |

## 5. 十篇核心教程的依赖顺序

每一项都需要独立英文与中文正文；两种语言共同维护稳定 article ID。沿用“问题→简答→直觉→原理→可视化→真实案例→误区→练习→延伸阅读→来源”，并为技术推导提供可选深读层。

| 顺序 | English                      | 简体中文                   | 学习依赖／重点                                                     |
| ---- | ---------------------------- | -------------------------- | ------------------------------------------------------------------ |
| 1    | What Is Photography?         | 摄影究竟是什么？           | 从观察、光线和表达出发，避免把购买器材作为学习起点                 |
| 2    | How a Digital Camera Works   | 数码相机如何成像？         | 镜头、光阑、快门、传感器、信号与成片流程                           |
| 3    | Sensor Sizes Explained       | 全画幅、APS-C 与传感器尺寸 | 实际尺寸、面积与长宽比，现代 APS-C 俗称不等于传统 half-frame       |
| 4    | Focal Length and Crop Factor | 焦距、画幅系数与等效焦距   | 基于第3篇解释等效视角，区分物理焦距、裁切和透视                    |
| 5    | Understanding Aperture       | 光圈到底是什么？           | 定义入瞳与 F 数值；最大／当前／最小光圈；变量最大光圈镜头案例      |
| 6    | Understanding Shutter Speed  | 快门速度与运动模糊         | 积分时间、主体运动、手持抖动、防抖及滚动失真分别说明               |
| 7    | What ISO Really Means        | ISO 究竟改变了什么？       | 光子信号、增益、输出映射、噪声和高光余量；承接光圈与快门           |
| 8    | Understanding Exposure Stops | 曝光档位与参数关系         | 用比例和对数串联第5—7篇；分别计算光曝光与输出亮度                  |
| 9    | Understanding Depth of Field | 景深、对焦与背景虚化       | 声明距离、视角、观看条件和模型；景深与背景模糊不混为单一指标       |
| 10   | RAW, JPEG and EXIF           | 照片格式与拍摄元数据       | 基于成像流程讲文件用途和处理差异；EXIF可缺失且不能证明全部拍摄条件 |

既有三篇基础教程应审阅、迁移、扩写后纳入该体系；不能仅更名并计入“完整教程”。当前曝光三角可作为学习入口或与第8篇关联，但不能代替光圈、快门、ISO的独立完整解释。

MVP 之后优先补充 P/A/S/M、曝光补偿、自动对焦、白平衡、胶片模拟、构图、风景、人物和两份具体器材操作指南。完整选题池保存在项目愿景／内容规划中，按依赖、实用性与来源可得性逐步推进。

## 7. 统一质量门槛与验收记录

1. **类型与构建：** 使用选定 runtime 和锁定依赖执行类型检查及静态构建。当前 `build` 已含 `astro check`；在检查通过后再判断是否需要拆分独立命令。任何失败应记录直接原因和影响范围。
2. **格式：** 运行当前 `format:check`。格式失败应与构建失败分开报告；修改仅涉及相关文件，避免无关全仓格式重写。
3. **路由与内部链接：** 既有 smoke 持续通过，同时检查新路由、译文落点、片段锚点、资源路径、未知路径状态码，以及根路径／模拟子路径两套配置。已有 smoke 不覆盖的部分必须另验。
4. **搜索：** 对最新静态产物使用有预期命中的中英文查询，检查结果标题、语言与落点。记录搜索覆盖 Learn 或全站的范围，不能用“索引已生成”代替可用性。
5. **数据：** 必需字段、唯一ID、译文配对、跨实体引用、机身／镜头兼容和画廊scope均校验；未核实链接不能成为 Verified，未知EXIF状态不能冒充支持。
6. **科学性：** 公式测试与编辑审查互补。每篇技术内容定义符号、单位、假设和参考来源；中英文解释一致，避免不合理的绝对结论。
7. **真实交互：** 检查数值输入、滑块、筛选、重置、语言切换、键盘和无脚本回退；不为静态文本增加机械测试，但关键计算必须有单元测试。
8. **移动端与无障碍：** 代表性手机、平板和桌面视口检查；窄屏无明显溢出、输入可触控、焦点可见、缩放可用。WCAG 2.2 AA是设计目标，未经完整审计不宣称认证或全面达标。
9. **版权与隐私：** 不复制无授权样片，不捏造EXIF或拍摄经历，不加入密钥。代码、文章和作品的权利说明分清，保留现有MIT通知。
10. **发布：** 本地MVP通过与正式部署是两个验收节点。只有取得发布授权后，才在选定平台验证base、404、搜索、缓存、安全头和真实公开URL；未通过就不报告上线成功。

每个批次的验收记录应包含：代码范围／版本、Node与包管理器版本、执行命令、通过／失败／未运行状态、人工检查页面与视口、未解决限制。仅在相关检查确实运行后更新完成状态；旧截图、旧dist或此前助手总结不能替代当前证据。
