# 内容与科学编辑规范

状态：Phase 1 设计规范，尚未实现为内容 schema、自动检查或发布流程。  
编写日期：2026-10-28。本文规定后续内容应达到的标准，不表示现有文章已通过审核。

## 1. 教学目标与适用范围

Photography Field Guide 帮助初学者理解参数之间的因果关系，并通过控制变量形成自己的判断。文章围绕真实问题组织，先解释能用来做决定的概念，再提供可选的物理推导。器材用于展示原理，避免购买导向、排名、营销评价和无条件的“推荐参数”。

当前已有导览和三篇双语概念稿，应视为扩写基础；不能因为网页可以打开就将其计为完整核心教程。第一批完整教程为摄影是什么、数码相机成像、传感器尺寸、焦距与画幅系数、光圈、快门、ISO、曝光档位、景深，以及 RAW/JPEG/EXIF，共十个主题、每个主题两种语言。

## 2. 核心教程的十段结构

| 顺序 | 英文标题              | 中文标题与要求                                                     |
| ---- | --------------------- | ------------------------------------------------------------------ |

| 2    | Short Answer          | 简短回答：用 2–5 句话给出结论，同时保留必要条件。                  |
| 3    | Intuition             | 直观理解：建立类比或因果解释，指出类比失效之处。                   |
| 4    | How It Works          | 原理：定义术语、单位、公式符号、假设和适用范围。                   |

| 6    | Real-World Example    | 真实案例：把概念放入明确的设备和场景中；演算案例不能冒充真实拍摄。 |

这些段落是核心教程的编辑要求，不靠空标题满足数量。可以根据阅读节奏合并相邻小节，但审查时必须能找到每项教学职责。术语短定义、资源条目和器材规格表不必强行套用长教程结构。

## 3. 分层阅读

Beginner 层回答“这是什么、会改变什么、我可以怎样试”；应在不阅读推导的情况下成立。Deeper Understanding 层解释条件、因果关系和参数的联系。Technical Notes 层承载数学推导、模型限制和实现细节，可使用可访问的折叠块，但不能把影响结论正确性的限制藏在折叠内容中。

每个公式第一次出现时定义全部符号并说明单位。正文采用可访问的数学排版，不能只把公式放在图片中。近似值使用“约”或“≈”，显示精度不能超过输入和模型能支持的精度。

## 4. 摄影科学口径

### 4.1 画幅、焦距、视角与透视

物理焦距是镜头的光学属性，改变传感器尺寸不会把 16 mm 镜头变成 24 mm 镜头。等效焦距描述与指定参考画幅的视角比较。画幅系数默认按对角线定义：

`c = sqrt(w_ref² + h_ref²) / sqrt(w_target² + h_target²)`

`f_equivalent = f_actual × c`

参考画幅、宽高尺寸和单位必须随结果展示。区分“约 1.5× 的常用系数”和由某机型真实尺寸计算的数值；不得把两种算法包装成同一种精确结果。不同宽高比的画幅只能按选定方向或对角线比较；按对角线等效不会同时保证水平和垂直视角相同。

对直线投影、理想化无限远对焦模型，可用 `angle = 2 × atan(sensor_dimension / (2 × focal_length))` 解释相应方向的视角。鱼眼投影、近距离对焦、呼吸效应和软件裁切可能超出这一模型。示意图应声明这些条件。

透视由视点决定。换焦距、换画幅、裁切和移动相机是不同操作；不能把裁切直接称为镜头的光学放大。“半画幅”不是现代 APS-C 面积恰为全画幅一半的数学定义，也应与传统胶片 half-frame 区分。

### 4.2 光圈

使用 `N = f / D` 定义 F-number，其中 `D` 是入瞳直径，不能未经说明替换成光阑叶片开口的几何直径。标称光圈与近距离拍摄中的有效光圈问题应分层说明。

在相同场景亮度、近似相同镜头透过率和适用的理想化条件下，像面辐照度近似正比于 `1 / N²`。f/2.8 到 f/4 约减少一档；标称数值经过取整，不应声称该比值严格等于 2。

区分最大光圈、当前光圈、最小光圈、入瞳直径、景深和衍射。XF16–50mmF2.8–4.8 的标注描述变焦两端的最大光圈，不表示镜头只能在 f/2.8 到 f/4.8 之间使用。没有来源时不推测每个中间焦距对应的最大光圈。

### 4.3 快门与模糊

快门时间影响光的积分时间，也影响主体运动和相机运动造成的模糊。区分手持抖动、主体运动、对焦错误、电子快门滚动失真和镜头光学问题。IBIS/OIS 可以补偿某些相机运动，不能冻结运动主体。经验性安全快门必须写明焦距、观看要求、像素密度、持机方式和个体差异等条件，不能当作硬物理定律。

### 4.4 ISO、光曝光与输出亮度

光圈和快门直接参与决定像面光曝光；ISO 主要影响信号处理和输出亮度映射。固定光圈、快门和场景时，提高 ISO 不会增加到达传感器的光子数。模拟增益、数字处理、高光余量、读出噪声和自动曝光联动，应按机型和讨论层次分别解释。

“曝光三角”可以作入门模型，但必须指出三项控制对光子数的作用不等价。不得写“ISO 越低画质永远越好”，也不能用自动模式下快门变化造成的光子数变化，证明 ISO 本身改变了入射光子数。

比较两组设置时，令快门时间为 `t`、光圈系数为 `N`：

`Δ光曝光档数 = log2(t₂ / t₁) − 2 × log2(N₂ / N₁)`

在理想化线性亮度映射假设下，另行计算 `Δ输出亮度档数 = Δ光曝光档数 + log2(ISO₂ / ISO₁)`。结果应明确标为相对设置比较，不冒充真实相机 JPEG 像素值预测。图像曲线、饱和、机型标定和自动处理会限制这一简化模型。

### 4.5 总光量、景深与虚化等效

同样的单位面积光曝光并不意味着同样的传感器总接收光量。在相同平均像面照度、积分时间和相关光学条件下，总入射光量可按有效面积比较；不能只凭画幅大小预测所有场景的画质或噪声。

讨论景深等效时，至少声明相同视角、相同拍摄距离、相同对焦主体和相同最终观看条件。在常用近似下，可用 `N_reference ≈ c × N_target` 作景深比较；这不改变镜头实际 F-number，也不是要求把曝光参数乘以画幅系数。

景深是符合某种可接受清晰标准的范围，背景虚化还取决于背景距离、放大倍率、入瞳、像差及观看条件。景深工具必须显示容许弥散圆或其选取规则，说明薄透镜等模型假设，并正确处理远界为无穷远等情况。不得将其称为真实镜头的完整效果模拟。

### 4.6 解析力、格式与胶片模拟

实际细节由传感器采样、镜头 MTF、像差、衍射、对焦、运动、处理和观看条件共同决定。像素数不能直接当作最终解析力；“套头一定差”“昂贵镜头一定更清晰”不能作为无条件结论。

RAW、JPEG、HEIF 与 EXIF 应分别解释为数据/编码/元数据相关概念。不能保证每个分享平台保留全部 EXIF，也不能从缺少 EXIF 推断拍摄者未使用某设置。胶片模拟须区分 Fujifilm 内置模拟、第三方 Recipes、LUT、RAW 转换和预设；配方代际兼容性和菜单行为以实际机型官方资料及可重复验证为准。

## 5. 真实设备与案例

第一批示例优先采用 Fujifilm X-T5 和 XF16–50mmF2.8–4.8 R LM WR，但内容结构保持品牌中立。涉及精确尺寸、像素、卡口、防抖、文件格式、光圈范围、固件或操作方式时，引用相应官方规格或说明书，记录版本、区域语言和核查时间。

X-T5 的实体拨盘行为不能直接套用其他相机的 PASM 模式拨盘叙述。R、LM、WR、OIS 要分别解释；没有镜头 OIS 不等于没有机身防抖，WR 不等于完全防水。厂商“约 24–76 mm 等效”的标注和使用 1.5× 得到的近似演算可并列解释，不能悄悄替换来源数值。

演算案例须标“示例设置”或“假设条件”；真实照片须有可核实的授权、署名和参数来源。没有可使用照片时，使用原创 SVG 或外部文本链接，不捏造创始人的拍摄经历、照片或 EXIF。

## 6. 图示与交互规范

每幅图标记为实拍、按几何计算的示意、或概念插图。尺寸比较图必须采用统一物理缩放；使用失真或非按比例绘图时，要在图旁注明。图例同时使用文字、线型或纹理，不能仅依赖颜色区分。

交互控件有可见标签、单位、键盘操作、错误提示和可读结果；数字输入与滑块同步。结果需呈现模型条件，而非只给一个数值。非法、非有限、零或负值以及超出模型范围的输入不能产生貌似合理的结果。动画尊重减少动画偏好；工具加载失败时保留静态解释。

## 7. 双语与术语

英文是默认语言，中文是简体中文；相同内容使用稳定 ID 和相同 slug 关联。正文、图注、图例、表格、控件、错误信息、示例、练习、来源说明和 SEO 均需翻译。正式双语教程两种语言都应满足同一教学结构，不能将导航翻译视为正文翻译完成。

| English                 | 首选中文           | 别名或注意事项                      |
| ----------------------- | ------------------ | ----------------------------------- |
| Aperture                | 光圈               | 按语境区分开口、F-number 和设置值。 |
| F-number                | 光圈系数（F 数值） | 不与入瞳直径混用。                  |
| Entrance Pupil          | 入瞳               | 不直接等同物理光阑开口。            |
| Shutter Speed           | 快门速度           | 公式中用快门时间，单位秒。          |
| ISO Sensitivity         | ISO 感光度         | 不暗示增加入射光子数。              |
| Crop Factor             | 画幅系数           | 保留“裁切系数”为检索别名。          |
| Equivalent Focal Length | 等效焦距           | 明确参考画幅与比较方向。            |
| Depth of Field          | 景深               | 与背景虚化分开解释。                |
| Field of View           | 视野范围           | 按语境明确范围或取景范围。          |
| Angle of View           | 视角               | 用角度或弧度标明数值单位。          |
| Exposure Compensation   | 曝光补偿           | 机型和模式决定具体联动。            |

| Motion Blur             | 运动模糊           | 区分主体运动与相机运动。            |
| Composition             | 构图               | 经验原则不包装成必守规则。          |

首次出现专业术语可附另一语言名称，此后保持一致。缺失译文要显示真实的回退说明；语言切换优先到同一文章，不能静默把读者送回首页。未实现对应机制前，不能宣称已完成回退能力。

## 8. 内容元数据与来源

建议扩展 Starlight 的 `docsSchema()`，保留其文档能力，并为教程增加稳定 `translationKey`、语言/翻译关联、摘要、难度、分类、前置文章、相关术语、相关工具、来源、状态和 `lastReviewed`。具体字段名以架构文档最终 schema 为准，本规范不表示这些字段已经存在。

首版状态区分 `draft`、`in-review` 和 `published`；`archived` 在具备实际归档策略后再扩展；只有完成审查才记录审核状态。`lastReviewed` 是最近一次实质内容核查日期，不是文件修改时间、构建时间或批量生成日期。来源至少保留标题、发布者、URL、核查日期和它支持的主张；软件/固件/说明书另记适用版本或章节。

物理推导要能追溯定义及假设。器材规格优先官方资料；独立评测和社区体验可用于实际观察，须标明其性质，不能覆盖客观规格。仅链接首页不足以证明具体参数。没有完成核查的来源保留待核查状态，不填写虚假的核查日期。

## 9. 发布审查与修订

每篇核心教程发布前按以下顺序审查：

1. 检查问题、短答和结论是否一致，初学者能否独立理解。
2. 检查因果关系、术语、公式、单位、近似和适用条件，删除不合理的绝对化结论。
3. 复算数值示例；检查图与计算公式是否描述同一条件。
4. 核查型号、菜单、固件和外链，逐项确认来源真正支持主张。
5. 试走练习，检查步骤、控制变量、预期观察与反思问题。
6. 对照中英版本的含义、图例、数字、错误信息和引用。
7. 检查站内引用、对应语言路径、搜索可发现性、移动阅读、键盘和替代文本。
8. 记录审核范围、证据和日期；解决阻断问题后再变更发布状态。

公式工具的单元测试至少覆盖 16 mm APS-C 约 24 mm 等效、不同画幅尺寸、f/2.8→f/4 约一档、快门时间加倍、ISO对亮度与光子数的区别、非法值和边界值。不能只验证界面文字。

用户报告科学错误后，先保存可复核的问题和依据，再修正文稿及对应译文；对改变读者操作判断的修订记录变更说明。不要在没有检查另一语言的情况下自动更新其审核日期。
