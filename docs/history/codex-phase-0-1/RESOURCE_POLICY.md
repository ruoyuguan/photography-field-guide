# 外部资源与样片索引政策

状态：Phase 1 设计规范，尚未实现为资源集合、界面标签或自动检查。  
编写日期：2026-10-28。本文件不表示种子资源已逐项核查，也不表示项目已获转载、下载或嵌入许可。

## 1. 目录用途

Resources 整理有明确学习用途的外部资料；Galleries 整理外部样片入口。默认以文本链接引导读者访问原始页面。器材页、教程和词典复用这些条目的稳定 ID，避免在多个页面维护相互矛盾的资源描述。

每条资源解释它能帮助解决什么问题、适合哪个学习阶段、内容来自谁、使用哪种语言，以及有哪些已知限制。流量、品牌或用户数量不等同权威性；产品规格、独立测量和主观体验应分别标注。

## 2. 五个互相独立的核查维度

| 维度         | 要回答的问题                   | 建议记录                                                                                       |
| ------------ | ------------------------------ | ---------------------------------------------------------------------------------------------- |
| official     | 是否由所声称的官方主体提供？   | 布尔值或未知值、主体、证明依据；不能仅凭标题或Logo。                                           |
| availability | 当前能否访问预期内容？         | `unchecked / accessible / blocked / broken`、最终URL、HTTP结果（如可得）、核查时间、访问限制。 |
| identity     | 页面是不是条目声称的资源？     | `unchecked / confirmed / mismatch`、实际标题、提供者、对象型号、语言和依据。                   |
| rights       | 本站能够怎样使用该内容？       | 默认仅文本链接；许可证/授权范围、署名、限制和证据；未知不等于允许转载。                        |
| scope        | 链接及其证据支持什么对象范围？ | `camera / lens / camera-lens-combination / photographer / general-gallery`及范围依据。         |

这些状态不能合并成一个无条件的“Verified”。官方身份不证明每句话都正确；HTTP 200 不证明页面身份正确；准确的机型标题不证明照片参数和许可；能够下载文件不证明允许转载。

可以在界面显示“链接与页面范围已核查，日期……”等准确文字。如果保留总括 `verificationStatus`，它必须由所需维度和证据推导，并在标签旁说明核查范围。任何维度未检查或冲突时，不能展示会使读者误解为全面背书的“已验证”。

## 3. 可追溯的核查记录

一次人工核查至少记录：原始URL、最终URL、时间、方法、实际页面标题、提供者、条目用途、支持范围的页面证据，以及核查结果。证据可以是章节、明确的文字说明或某张照片的可见元数据引用；避免为取证保存不必要的第三方图片或个人信息。

`lastChecked` 表示最近尝试检查的时间，失败也可以记录；`lastVerified` 只记录相关内容真正核验成功的时间，并注明核查了哪些维度。不得在导入种子列表、执行构建或自动收到HTTP成功后批量填入 `lastVerified`。

自动检查只负责有限结论：URL格式、重定向、状态码和可达性等。验证码、登录墙、地区限制、机器人拦截、超时和 403 应记录为受限/待人工检查，不能一律称为失效。重定向至主页、促销页或其他型号时，HTTP成功仍可能是身份不匹配。

核查程序不得绕过访问控制或批量抓取摄影作品。需要登录的资源可保留限制说明；若内容不可见则不推断其内部字段。

## 4. 样片范围与组合证据

相机画廊只支持相机范围，镜头画廊只支持镜头范围。X-T5画廊可能包含多支镜头，XF16–50mm画廊可能包含多种机身。两个链接同时存在、照片风格相似或机身和镜头在技术上兼容，都不能作为特定组合的证据。

只有明确的页面范围声明或可核查的逐张照片信息支持时，才能标记 `camera-lens-combination`。如果仅部分照片有组合证据，条目应链接或描述这些具体照片，并声明范围，不能把整个混合画廊标记成全部使用该组合。

`cameraId`、`lensId` 是本站实体引用；填写前核对完整型号、卡口和变体。未知值留空，不能用“最可能的套机镜头”补全。适配器、裁切模式或后期处理信息未提供时，应保留未知。

标签用来组织摄影主题，如建筑、街头、人像和风景；它们不是对每张照片拍摄内容或设备的保证。来源平台与来源性质分别记录，区分官方、独立编辑机构和用户社区。

## 5. EXIF、原始文件与真实性

EXIF和原始文件能力至少使用 `unknown / available / unavailable` 三态，而非把未检查表示成“没有”。区分页面可见参数、下载文件中的嵌入元数据、可下载高分辨率JPEG，以及真正的相机RAW文件。

只检查某张照片不能证明整个画廊都有EXIF或RAW。条目应记录实际检查范围；不明确的情况显示“部分样片提供”或“未知”。平台可能移除元数据，EXIF本身也可能被修改，因此它是来源证据之一，不是未经条件的真实性证明。

不能将人工填入的示例参数伪装为照片EXIF，不从画面外观反推确定参数，也不把生成图片当作相机实拍。未来本地EXIF工具应默认在浏览器处理文件，提醒GPS、时间等字段可能包含隐私信息；在实际实现之前不展示假上传流程。

## 6. 图片版权与使用范围

资源目录默认只提供文本介绍和原始页面链接，不批量下载、缓存、热链或重发第三方照片。平台提供下载按钮、网页可公开访问、作品属于官方样片，都不自动等于本站有复制或嵌入许可。

使用图片前逐项核对许可主体、具体作品、授权用途、允许的修改、署名方式和限制。授权只覆盖某作品时，不扩展至同站其他作品。外链许可与图片许可分别判断；转载授权不自动允许删除水印、原始署名或元数据。

创始人提供照片时仍需确认是否同意公开及采用什么许可。沿用ScrewFast的代码许可证要求；原创文章、代码和照片的许可不能相互推定。本文件不选择或更换任何项目许可证。

## 7. 条目最小字段

ExternalResource 建议包含稳定 `id`、双语标题/简介、`provider`、类别、URL、官方身份、资源语言、用途、学习阶段、标签、可达性、身份核查、权利说明、核查记录与时间。

GalleryLink 在上述共用字段之外包含 `scope`、可选 `cameraId`/`lensId`、主题、来源平台、来源性质、EXIF能力、原始文件能力和范围证据。器材规格的来源引用应指向其真正支持的页面或说明书章节，而非只链接画廊。

数据实现应保证ID唯一、引用存在、枚举合法，且不允许缺失证据的条目自动进入已核查状态。具体字段名与内容集合拆分以架构文档最终实现为准；避免为目录建立不必要的数据库或自定义内容框架。

## 9. 维护与发布门槛

首次发布前逐项人工检查将展示的种子资源；上线后可采用定期自动可达性检查，加上按内容重要性安排的人工复核。故障或内容变更时保留既往记录，更新当前状态，不通过刷新日期掩盖失败。

发布检查至少确认：

1. 标题、说明、语言和对象范围与目标页面相符。
2. 官方身份和第三方身份有依据，且没有被混同为科学权威评级。
3. 机身/镜头引用正确，组合声明有直接证据。
4. EXIF与原始文件能力按实际检查范围展示，未知没有被写成确定值。
5. 权利说明与实际展示方式一致，没有未经许可的图片复制。
6. 中英文描述含义一致，链接可操作，可访问性与外链行为明确。
7. 核查状态、证据和日期可追溯，自动可达性结果没有被夸大成内容核验。

失效链接可以隐藏、标记不可用或替换为经过核验的新入口。遇到版权异议或身份争议时先停止有争议的展示方式，再保留必要证据并处理修订；不因为目录已发布就推定权利已经成立。
