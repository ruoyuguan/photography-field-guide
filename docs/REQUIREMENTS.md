# 1. 项目背景

## 1.1 为什么要建设这个网站

我是一名物理学博士生，也是一名刚开始系统学习摄影的爱好者。

在学习摄影的过程中，我发现许多概念对初学者并不直观。

例如：

- 为什么相机有全画幅、APS-C、M4/3、中画幅？
- “半画幅”是什么意思？是不是传感器面积只有全画幅的一半？
- 为什么 16mm 镜头在 APS-C 相机上常被称为等效 24mm？
- 等效焦距是否意味着镜头本身的焦距发生变化？
- 光圈 F2.8、F4、F8 代表什么？
- F 数值越小为什么光圈反而越大？
- 光圈与焦距之间有什么物理关系？
- 什么是进光量、曝光量、图像亮度？
- 为什么 ISO 提高通常会让照片更亮，却不意味着传感器接收到了更多光子？
- 快门速度为什么既影响亮度，也影响运动模糊？
- 为什么一张照片会因为相机抖动而模糊？
- 景深与焦距、光圈、拍摄距离和传感器尺寸有什么关系？
- 为什么 40MP 相机不意味着每支镜头都能提供相同的实际解析力？
- 为什么同一张照片可以有不同的曝光参数？
- 什么是 EXIF？
- 为什么能够通过别人的样片反过来学习摄影参数？
- 什么是 RAW、JPEG、HEIF？
- 富士胶片模拟与第三方 Film Simulation Recipes 有什么区别？
- 什么是构图？摄影审美应如何培养？
- 学习摄影是否必须从复杂的后期处理开始？
- 如何选择值得信赖的学习网站、摄影社区和样片资源？

这些问题看似简单，但如果缺少完整的物理解释和具体示例，初学者往往只能记住零散结论。

本项目希望解决这个问题。

## 1.2 网站的教学理念

每一个摄影知识点都应尽可能遵循下面的教学流程：

**实际问题 → 直观解释 → 物理原理 → 参数变化 → 可视化比较 → 拍摄实例 → 实践练习 → 延伸资源。**

例如，讲解 APS-C 和全画幅时：

1. 先说明相机传感器是什么；
2. 展示不同传感器的物理尺寸；
3. 解释为什么使用相同镜头时视角不同；
4. 引入 Crop Factor；
5. 推导等效焦距；
6. 使用真实镜头数值举例；
7. 比较同一位置、同一焦距下不同画幅的取景范围；
8. 解释等效焦距与透视的区别；
9. 最后提供相机、镜头样片和练习建议。

不要只写：“APS-C 焦距乘以 1.5 即可”。

读者需要理解这个 1.5 从哪里来，以及它有什么适用条件。

## 1.3 预期用户

主要用户包括：

1. 完全没有摄影基础的新手；
2. 刚刚购买第一台可换镜头相机的用户；
3. 了解少量摄影术语，但不能系统理解参数关系的用户；
4. 希望通过真实样片理解相机和镜头表现的人；
5. 使用 Fujifilm X 系列相机的摄影爱好者；
6. 喜欢理解物理原理的进阶学习者。

网站必须兼顾初学者和更深入的学习需求。

不能假设读者具有物理学、光学或摄影知识。

但也不能为了通俗而牺牲科学严谨性。

# 2. 项目的整体定位与边界

## 2.1 核心定位

Photography Field Guide 是一个以静态摄影为核心的摄影知识指南。

它应当同时具备以下性质：

**Educational Reference**

解释摄影的概念、原理和术语。

**Interactive Learning**

通过可视化和计算工具帮助读者建立直觉。

**Practical Field Guide**

根据实际拍摄场景提供有条件、有解释的操作建议。

**Curated Resource Directory**

整理值得信赖的外部学习网站、官方资料、社区和样片画廊。

**Equipment Case Studies**

使用真实器材展示如何把理论应用到实际设备上。

## 2.2 不应成为以下类型的网站

不要将其改造成：

- 电子商务网站；
- 相机导购或带货网站；
- 器材评测排名网站；
- 依赖广告收入的 SEO 内容农场；
- 专门讨论摄影器材价格的网站；
- 充满营销口号的 SaaS Landing Page；
- 以个人社交动态为中心的摄影社区；
- 需要登录账号才能学习的网站。

网站可以介绍器材，但目的应该是帮助读者理解和使用器材，而不是刺激购买。

## 2.3 内容优先级

优先级从高到低：

1. 摄影基本原理；
2. 摄影参数及其相互关系；
3. 真实拍摄场景；
4. 交互式辅助学习；
5. 摄影术语词典；
6. 可信资源与样片画廊；
7. 具体器材使用指南；
8. 摄影实践与构图；
9. 个人摄影笔记；
10. 视频摄影知识。

视频知识可以预留结构，但第一阶段不应成为重点。

## 3.2 镜头

**FUJINON XF16-50mmF2.8-4.8 R LM WR**

这是网站第一支需要完整解释的镜头。

其重要参数包括：

- 物理焦距范围：16–50mm；
- 适用于 Fujifilm APS-C 相机；
- 35mm 全画幅等效焦距约 24–76mm，官方具体数值以厂商标注为准；
- 最大光圈随焦距变化，范围为 F2.8–F4.8；
- 具备光圈环；
- 具备 LM 对焦机构；
- 具备 WR 防尘防滴设计；
- 镜头不包含 OIS 光学防抖；
- 是兼顾便携和高像素机身的标准变焦镜头。

讲解镜头时，应以这支镜头作为贯穿多个章节的真实例子。

特别需要解释：

- 为什么写作 XF16–50mm，而不是 XF24–76mm；
- 为什么最大光圈同时有 F2.8 和 F4.8；
- 最大光圈与最小光圈的区别；
- 为什么 F2.8–4.8 的镜头依然可以设置到 F8；
- R、LM、WR 和 OIS 分别代表什么；
- 为什么镜头没有 OIS 不等于相机没有防抖；
- 为什么 WR 不代表完全防水；
- 16mm、23mm、35mm、50mm 分别适合什么视角和构图；
- 变焦镜头与定焦镜头的实际差别；
- 如何判断镜头是否足以满足自己的拍摄需求；
- 什么是中心锐度、边缘锐度、光学像差、MTF 与衍射；
- 为什么机身像素数不等于真实照片的可分辨细节量。

涉及镜头最大光圈与焦距之间的精确变化关系时，不要凭空编造未核实的数据。

在设计网站内容时，需要知道以下背景：

这些偏好可以影响第一批案例的选择，但不能把网站限制为个人设备使用手册。

# 5. 教学内容的写作标准

每一篇核心教程必须使用稳定、可复用的结构。

推荐结构：

## The Question / 你可能遇到的问题

使用新手熟悉的表达方式提出真实问题。

## Short Answer / 简短回答

用 2–5 句话解释最重要的结论。

## Intuition / 直观理解

不用复杂公式，让初学者建立初步直觉。

## How It Works / 原理

引入必要的光学、数学或数字成像知识。

## Visual Explanation / 可视化

尽可能使用：

- 原创示意图；
- SVG；
- 参数对照；
- 表格；
- 可交互组件；
- 获得明确授权的样片。

## Real-World Example / 真实案例

优先使用已知的 Fujifilm X-T5 和 XF16–50mm 作为例子。

## Common Misconceptions / 常见误区

指出常见但不严谨的说法。

## Try It Yourself / 动手练习

设计能够在真实相机上重复执行的练习。

## Further Reading / 延伸阅读

包括相关站内文章和外部权威资源。

## Sources / 参考来源

记录主要事实、公式及型号规格的出处。

### 分层阅读

每篇文章应区分三个层次：

**Beginner**：只需要理解概念和操作。

**Deeper Understanding**：解释因果关系、适用条件和参数之间的联系。

**Technical Notes**：可选的数学推导、光学解释、技术限制。

不要在初学者第一屏直接堆砌公式。

也不要因为初学者可能不熟悉公式，就完全删掉科学依据。

# 6. 必须遵守的摄影科学准确性要求

本网站的内容质量必须高于一般的参数速查博客。

以下原则属于不可忽略的编辑标准。

## 6.1 焦距和等效焦距

物理焦距是镜头的光学属性。

当同一支镜头用于不同尺寸的传感器时，镜头的物理焦距并不会改变。

等效焦距通常用于描述与指定参考画幅具有近似相同视角的焦距。

例如：

16mm × 1.5 ≈ 24mm。

但应明确：

- 这里的 1.5 是近似画幅系数；
- Fujifilm APS-C 的实际尺寸决定了更精确的系数；
- 等效焦距不意味着实际焦距改变；
- 不能把裁切直接称作镜头光学放大；
- 相机位置决定透视关系；
- 更换焦距与移动相机不是同一种操作。

同时区分：

- 视角变化；
- 透视变化；
- 取景范围变化；
- 景深变化。

## 6.2 传感器尺寸

解释全画幅、APS-C、M4/3 和中画幅时，应使用真实尺寸或合理的代表尺寸，并说明同一类别内部可能存在差异。

不要把“半画幅”直接解释成面积恰好等于全画幅的一半。

也应区分现代摄影圈对 APS-C 的俗称，与传统胶片摄影中的 half-frame format。

## 6.3 光圈

解释：

N = f / D

其中：

- N 是 F-number；
- f 是焦距；
- D 是入瞳直径。

严格区分入瞳直径与镜头内部光阑开口的几何尺寸。

对于固定条件下的理想化比较，进入成像系统的辐照度与 F-number 的平方近似成反比。

解释为什么从 F2.8 改为 F4 约减少一档曝光，而不是简单减少一个固定百分比。

区分：

- 最大光圈；
- 当前光圈；
- 最小光圈；
- 景深；
- 曝光；
- 衍射。

不得将“最大光圈 F2.8–4.8”错误解释为镜头只能使用这两个 F-number 范围内的光圈。

## 6.4 快门

快门时间影响光的积分时间和运动模糊。

必须区分：

- 手持抖动；
- 主体运动；
- 电子快门滚动失真；
- 机械快门；
- 机身防抖与镜头防抖。

例如：

IBIS 可以降低部分手持相机抖动，但不能让正在奔跑的人停止运动。

## 6.5 ISO

不要将 ISO 直接解释成传感器“吸收更多光”。

在光圈与快门时间不变时，提高 ISO 通常不意味着传感器捕获更多光子。

要解释：

- 光子信号；
- 模拟/数字增益；
- 输出亮度；
- 噪声；
- 高光余量；
- 相机处理；
- 不同设备的实现差异。

不要使用“ISO 越低画质永远越好”一类绝对化陈述。

## 6.6 曝光三角

可以使用“曝光三角”作为教学模型，但必须在更深层解释中说明：

光圈和快门直接参与决定传感器接收到的光曝光量；ISO 主要影响信号处理与图像亮度的映射。

不要让用户误以为三个参数对入射光子数的作用完全等价。

## 6.7 景深等效

在比较不同画幅的背景虚化时，必须声明比较条件。

例如：

- 相同视角；
- 相同拍摄距离；
- 相同最终观看条件；
- 相近的对焦和光学条件。

应解释：在常见等效比较中，F-number 可以用于近似比较景深表现，但不意味着镜头实际 F-number 或单位面积曝光发生改变。

不要在缺乏条件说明的情况下直接声称 APS-C 的 F2.8 就是全画幅的 F4.2。

## 6.8 解析力

不能把机身像素数与实际成像细节简单划等号。

讲解：

- 传感器采样；
- 镜头 MTF；
- 光学像差；
- 衍射；
- 对焦误差；
- 运动模糊；
- 后期锐化；
- 观看尺寸。

避免使用“狗头一定无法发挥高像素”“牛头一定更清晰”这样的绝对化语言。

## 6.9 胶片模拟

区分：

- Fujifilm 内置 Film Simulations；
- 第三方 Film Simulation Recipes；
- LUT；
- RAW 转换；
- 传统后期 Presets。

不得将 X-Trans 不同代际的配方兼容性未经核实地视作相同。

## 6.10 科学写作原则

每个技术性结论都应标明：

- 适用条件；
- 关键假设；
- 可能的例外；
- 数据或公式来源。

如果存在公认的近似，应明确写为近似。

如果存在不同的解释框架，应说明它们适用的比较条件，而不是制造错误的唯一结论。

# 7. 交互工具设计

本项目的优势不应只是图文内容，还应该体现在能够操作的知识可视化上。

请规划以下工具。

## 7.1 Crop Factor Calculator

画幅系数与等效焦距计算器。

输入：

- 参考画幅；
- 目标传感器规格；
- 镜头实际焦距。

输出：

- Crop Factor；
- 等效焦距；
- 取景视角的近似关系；
- 对概念的简短解释。

必须区分近似系数与使用真实尺寸计算得到的系数。

## 7.2 Field of View Visualizer

视角可视化工具。

允许用户改变：

- 传感器尺寸；
- 焦距；
- 取景方向；
- 距离等相关参数。

展示视野范围的变化。

可以使用 SVG 几何图或原创示意图。

应严格区分真实的视角几何计算与仅具有概念性作用的插画。

## 7.3 Exposure Stops Calculator

曝光档位计算器。

允许用户比较：

- 光圈变化；
- 快门时间变化；
- ISO 设置变化。

输出相应的曝光或输出亮度变化，并解释 ISO 的物理作用与另外两个参数之间的不同。

## 7.4 Aperture Demonstrator

光圈演示工具。

展示不同 F-number 对应的相对入瞳尺寸和相对照度关系。

不要用一幅画面暗示不同焦距的镜头只要 F-number 相同，物理入瞳直径就必然相同。

## 7.5 Depth of Field Explorer

景深学习工具。

允许选择：

- 传感器规格；
- 焦距；
- F-number；
- 对焦距离；
- 容许弥散圆等条件。

先展示简单的定性关系。

高级模式才使用明确假设下的景深估算公式。

必须说明这只是模型，不能冒充真实镜头所有成像特性的完整光学模拟。

## 7.6 Camera Settings Explorer

基于 Fujifilm X-T5 的参数探索器。

展示：

- 光圈优先；
- 快门优先；
- 手动曝光；
- Auto ISO；
- 曝光补偿；
- 对焦模式。

设置行为要参考真正的 X-T5 官方操作说明。

不要照搬其他品牌常见的 PASM 模式拨盘操作方式。

## 7.7 EXIF Reader

未来可以设计浏览器本地 EXIF 查看器。

优先纯客户端实现。

默认不要上传读者照片到服务器。

应明确告知用户 EXIF 可能包含：

- 拍摄时间；
- 设备信息；
- 焦距；
- 光圈；
- 快门；
- ISO；
- GPS 地理位置等敏感元数据。

如果暂时没有可靠的文件解析方案，先提供概念性文章，不要制作一个看似可用、实际不工作的上传表单。

## 实现约束

第一阶段优先完成：

1. 等效焦距与画幅系数计算器；
2. 曝光档位计算器。

其他工具可以先设计接口和数据模型，后续逐步实现。

所有计算工具必须进行边界输入校验，并有单元测试。

# 13. 视觉设计与用户体验

## 13.1 总体风格

网站应具有现代摄影杂志、专业知识手册和高质量科学教育网站的气质。

设计关键词：

- Minimal；
- Editorial；
- Timeless；
- Functional；
- Accessible；
- Photography-first；
- Quiet and precise。

不要采用典型商业 Landing Page 的浮夸设计。

## 13.2 视觉原则

以阅读舒适度为第一优先级。

建议：

- 简洁留白；
- 清晰的信息层次；
- 控制色彩数量；
- 优先中性色；
- 仅使用有限的强调色；
- 合理的正文字号与行距；
- 优秀的中英文排版；
- 简洁而易懂的图解；
- 适量而非大量的动效。

## 13.3 内容设计

科学公式应当排版正确。

示意图要有明确标注。

摄影图片与教学示意图应当区分。

不要使用虚构的照片和错误的 EXIF 数据来冒充真实样片。

如果无法获得使用权限，应使用原创 SVG 示意图或明确标注的占位设计。

## 13.4 首页

首页不应被大面积产品渲染图占满。

建议突出：

- 网站使命；
- 开始学习；
- 核心知识主题；
- 典型摄影问题；
- 少量交互工具；
- 精选资源。

## 13.5 响应式

必须支持：

- 桌面；
- 平板；
- 手机。

不能只在桌面设计稿上表现良好。

交互计算器必须在手机上可用。

## 13.6 无障碍

以 WCAG 2.2 AA 为目标进行设计和检查。

注意：

- 键盘导航；
- 可见的焦点状态；
- 颜色对比度；
- 图片替代文本；
- 表单标签；
- 不依赖颜色表达唯一信息；
- 减少动画偏好；
- 语义化 HTML。

# 17. 自动化检查与质量验收

开发时必须关注：

## 17.1 工程检查

- TypeScript 类型检查；
- Astro 构建；
- 格式检查；
- 现有 Smoke Tests；
- 路由有效性；
- 站内链接有效性；
- 关键页面的双语可访问性。

## 17.2 数据检查

- 不允许重复资源 ID；
- 不允许无效的内容引用；
- 不允许缺少必要字段；
- 不允许计算器在非法输入下返回误导性数值；
- 不允许错误匹配机身和镜头；
- 不允许未经核实的第三方样片链接被标记为 Verified。

## 17.3 科学准确性检查

为关键计算编写测试。

至少覆盖：

- APS-C 16mm 到约 24mm 等效焦距的计算；
- 不同画幅的 Crop Factor；
- F2.8 到 F4 近似一档的关系；
- 快门时间加倍与曝光档位；
- ISO 变化对输出亮度与光子数的区别；
- 非法焦距或传感器尺寸；
- 极端或边界输入。

测试不能只验证文字显示正确，还应验证公式及其适用条件。

## 17.4 内容审查

每篇正式发布的核心文章都应检查：

- 概念是否正确；
- 术语是否准确；
- 是否存在不合理的绝对化判断；
- 公式符号是否定义；
- 单位是否一致；
- 示例是否合理；
- 是否具有可靠来源；
- 中文和英文是否一致；
- 初学者能否理解；
- 是否包含真正有价值的练习或参考资料。

## 17.5 发布验收

不得出现：

- 未翻译的法语模板内容；
- ScrewFast 默认五金产品宣传；
- 虚构的产品或客户评价；
- 无意义的占位照片；
- 不能点击的按钮；
- 无功能的搜索；
- 虚构的摄影样片；
- 未验证的外部链接被声明已验证；
- 中文与英文切换后到达错误页面；
- 明显布局溢出；
- 基础构建失败。
