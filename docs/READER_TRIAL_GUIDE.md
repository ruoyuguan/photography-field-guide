# 小规模读者试用记录

用于下一次实际试用。当前没有真实读者结果，自动浏览器检查不能代替这份记录。英文与中文可分别邀请读者体验，不必要求他们两种语言都试。

## 准备

请读者从首页开始，用自己的话说出“现在想拍照、想理解概念，还是已有照片想整理”。不要先指给他正确按钮。暂未发布时可在本机试用；外地朋友需等实际部署后使用确认可用的网址，不能发 localhost。

照片始终留在读者自己的设备。无需提供照片、姓名、文件名、拍摄地点或私人笔记；只记录页面、操作和遇到的困惑。

## 四段观察

1. **找起点。** 请读者按自己的目标选择首页入口。记录他预期打开什么、实际打开什么，以及是否以为必须读完整个目录才能开始。
2. **做一个比较。** 在所选任务中预测一次，阅读反馈，尝试重试或查看解释。请他说明为什么需要固定某些条件、改变另一个条件。不要把答对当成已经理解。
3. **找到下一步。** 请他返回相关教程、回到任务目录并找到原任务，再选择一项建议练习。记录是否需要上下滚动寻找按钮、是否把建议当成强制解锁。
4. **回来继续。** 开始一项清单后刷新，或切换到对应语言，再回目录。请他解释继续入口和完成计数代表什么；它们只是本浏览器的自报清单，不是学习评分或跨设备同步。

有已有照片的读者可从 C4 开始，观察 C4 → C5 → C6 是否连贯。没有照片时用 C1，不必为了测试而上传或临时拍摄他人。

## 记录格式

| 页面／视口     | 读者想做什么 | 实际操作与原话摘要 | 需要帮助的位置 | 建议及依据 |
| -------------- | ------------ | ------------------ | -------------- | ---------- |
| 待实际试用填写 |              |                    |                |            |

只描述可观察事实，例如“返回目录后从顶部重找 C6”，不要写成“读者能力不足”。区分内容误解、入口命名、操作反馈、布局和存储预期。

## 下一轮改动标准

- 优先修复让读者无法继续、丢失进度或误解摄影因果的问题。
- 如果读者不能解释一个反馈，用更具体的情境或图示改进，再观察一次；不要直接增加更多术语。
- 保留任务自由进入、原片保护、无上传和无审美评分的方向。
- 根据具体观察决定改动，不因试用人数少就宣称所有新手都适用。发布后另验收实际域名、搜索和深层页面。
