## 1. 用户已明确的产品方向

- 项目是静态摄影教育手册、交互学习与可信资源目录，英文默认，简体中文切换。
- 最终设计原则是人类可读：内容呈现与网站逻辑交互共同控制认知负荷。
- 知识要能帮助读者理解因果、控制变量并独立判断，不以购买器材或复杂后期作为入门门槛。
- 通用工具使用全画幅、APS-C 等概念，具体设备用于专门器材页和合理案例。
- 练习希望有游戏式任务、反馈和进度；“光线侦探”“整理画面”“三张照片，一个地方”、“筛选、复盘、再拍”、C5“保留原片，导出副本”与 C6“轻量后期”已实现并接入统一目录。
- 本地开发统一在 /Users/ruoyu/photography-field-guide；保留现有工作和 Git 历史，正式发布、公开仓库和许可变更仍需明确授权。

## 5. 实拍与审美问题

- 照片为什么暗、为什么糊；人像背景为什么仍清楚？
- 夜景是否必须升ISO，风景是否必须F8，人像是否必须大光圈？
- 为什么快门不能只依据亮度决定；应该先调整哪个参数？
- 构图是什么，主体与视觉重点怎么建立？
- 三分法、引导线、对称、负空间、前中后景分别何时有用，何时可以打破？
- 光线方向、软硬、色彩、层次和情绪怎样影响表达？
- 怎样理解“糖水片”，是否可以用它练习，怎样看待不同目的的照片？
- 怎样阅读优秀作品，模仿后如何形成自己的观察？
- 怎样通过控制变量提高能力，怎样比较并复盘自己的照片？
- 城市建筑、街头、风景、人物、咖啡与食物、静物、夜景、旅行、阴雨、逆光和运动题材怎样逐步练习？

“看懂光线”已关联 `understanding-light` 教程和 `light-direction` 任务，覆盖方向、软硬、反差及控制变量复盘。“主体与背景”已关联 `subject-and-background` 教程和 `subject-background` 任务，覆盖机位与相对对齐、边缘、层次、留白和保留环境的理由；不把构图规则或背景模糊当作审美分数。“一次城市散步”已关联 `neighborhood-story` 教程与任务，覆盖环境／主体／细节的信息分工、三种实拍观察、排序与复盘。“照片筛选与复盘”已关联 `photo-review` 教程与任务，将近似分组、表达与技术比较、可撤销筛选和下一次实验串成闭环。C5 已关联 `backup-and-export` 教程与任务，解释原片、独立备份、用途导出与隐私。C6 已关联 `lightweight-editing` 教程与任务，独立比较明暗、白平衡与裁切，允许保留未改版本；色彩、情绪与优秀作品阅读可按读者需求后续扩展。
