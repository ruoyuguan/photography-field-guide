# Photography Field Guide — 项目愿景

日期：2026-10-28。状态：Phase 1 产品方向；已实现功能以审查报告为准。

## 项目与读者

**Photography Field Guide** 采用副标题 **An Open Guide to Understanding Photography**；中文为“摄影入门指南：从理解参数到独立创作”。这是以静态摄影为核心、英文默认并可切换简体中文的开放教育手册。它帮助初学者理解参数之间的因果关系，逐步形成观察、操作和创作判断力。

主要读者是零基础学习者、第一次使用可换镜头相机的人、希望系统理解术语的人，以及愿意深入了解成像原理的爱好者。技术说明以直观问题开篇，将公式和近似条件放进可选深读层；不以物理背景、昂贵设备或复杂后期软件作为学习门槛。

## 产品职责与优先级

Learn 负责完整教学；Glossary 负责快速查词与概念链接；Tools 用可操作模型建立直觉；Gear 把原理应用到真实设备；Galleries 引导阅读外部真实样片；Resources 记录可信资料的用途和证据；About 说明来源、编辑政策、版权及参与方式。Notes 在有实际原创记录后启用。

优先顺序是基本原理、参数关系、真实拍摄情境、交互学习、术语、可信资源、器材案例、实践与构图、笔记，最后才是视频内容。器材服务于学习，不设置价格排名、购买引导、虚构评价、登录门槛或营销转化目标。

## 教学体验

读者可以沿“问题 → 简答 → 直觉 → 原理 → 可视化 → 真实案例 → 误区 → 练习 → 延伸阅读 → 来源”学习，也可以从术语或工具直接进入相关教程。每个工具的结果都说明参考条件、单位、近似和限制，并提供返回完整解释的入口。

知识路线为 Getting Started、Sensor & Lens、Exposure、Image Quality、Composition、Field Practice、Workflow。文章按依赖顺序组织；章节与文章的实际可用性决定导航，不以空页面填满菜单。

## 真实案例与品牌中立

第一组案例是用户提供的 Fujifilm X-T5 与 FUJINON XF16–50mmF2.8–4.8 R LM WR；这些设备只是贯穿教程的例子，数据模型与知识体系应容纳其他品牌。

已核实的规格示例：X-T5 的标称传感器尺寸为 23.5 × 15.7 mm，有效像素约 40.2MP，采用 Fujifilm X 卡口。来源为 [Fujifilm 官方 X-T5 规格页](https://www.fujifilm-x.com/global/products/cameras/x-t5/specifications/)，2026-10-28 查阅。

镜头官方规格标注物理焦距 16–50 mm、35mm 格式等效 24–76 mm、最大光圈 F2.8–F4.8、最小光圈 F22。它们应分别保存为“厂商标注”与“模型计算”，不通过插值编造中间焦距的最大光圈。来源为 [Fujifilm 官方镜头规格页](https://www.fujifilm-x.com/global/products/lenses/xf16-50mmf28-48-r-lm-wr/specifications/)，2026-10-28 查阅。

例子优先选择城市、建筑、街头、风景、旅行、人物、咖啡与日常静物；直出 JPEG、胶片模拟和轻量工作流均有合理位置。内容不编造用户拍摄经历、作品、EXIF 或评价。用户的其他设备与后续主题保存在 [原始项目要求](PROJECT_BRIEF.md)，不据此扩张首版范围。

## 成功标准

读者应能解释 16 mm 在 APS-C 上为何常被称作约 24 mm 等效、为什么 ISO 变化不等于捕获更多光子、为何防抖不能冻结运动主体，以及怎样通过控制变量验证自己的理解。

产品验收同时考察概念准确、双语一致、实际可用、阅读舒适和长期可维护。首个完整 MVP 的数量与质量门槛见 [开发路线](ROADMAP.md)；本轮仅完成审查与设计。原始选题完整保存在 PROJECT_BRIEF.md，后续按知识依赖、实践价值和来源可得性整理，避免丢失创始人的真实问题。

## 视觉与维护

界面采用克制的摄影手册风格：中性色、有限琥珀强调、舒适留白、稳定中英文排版、原创标注图和适量动效。保留现有深色模式与响应式基础，以 WCAG 2.2 AA 为设计目标，实际符合程度通过检查记录表达。

维护者通过小批次改动、可核查来源、真实审核日期、双语配对、类型约束和关键公式测试保持质量。继续使用静态 Astro 与 Starlight，只有实际需求出现时才增加依赖。保留 ScrewFast 的现有 MIT 通知；原创文章与照片的许可另行决定。
