## 依据与范围

首页原本把画幅、焦距、曝光排成一条编号路径，而 Learn 导览从摄影与相机基础开始，Practice 又允许直接进入六个任务。已有照片想复盘的读者需要自行推断入口，六张长卡片也增加了寻找成本。C6 缺少直接回目录的结束入口，其他任务的目录返回主要位于页首。

这些是源码走查得到的可用性假设。本轮用自动浏览器验证实现，真实读者试用仍待执行，不能声称已经证明所有新手更易理解。

## 本批实现

- 首页与 Learn 共用三个入口：从零理解、马上拍摄、整理已有照片。手机上入口出现在画幅示意图之前；图示继续保留。
- Practice 新增紧凑路线图，区分准备拍新照片与整理现有照片；六项都能直接进入，编号只是建议。
- 继续入口读取原有两个进度空间。优先建议按课程顺序排列的进行中任务，再建议未开始任务，全部标记后提供复习入口。没有记录最近访问时间，也不将完成计数解释为掌握程度。
- 所有任务结尾共用相关教程、回目录与建议后续导航。回目录定位到原任务卡片，卡片可返回路线图；保留 C5 → C6 和 C6 复看备份教程。
- 将“先阅读教程”改为“相关教程”，避免暗示必修门槛；明确进度保存在当前浏览器，而非整台设备。
- 修正 Learn 的通用练习说明：比较光线方向时固定机位，比较机位时有意移动相机；固定条件取决于要比较的问题。

主要源码：`LearningStarts.astro`／`learning-starts.ts`、HomeView、两份 Learn 导览、PracticeOverview、MissionNavigation、PracticeIndexView、`suggestion.ts`、共享练习控制器和 `practice-paths.ts`。任务稳定 ID、版本、存储键及实际题目不变，没有新增账号、上传、自动评分或持久化字段。

## 本轮发现并修复的工程问题

1. **复核日期跨时区。** 北京时间 10 月 30 日对应 UTC 10 月 29 日傍晚，原 UTC 日期比较误判当天复核记录为未来。新增明确的 Asia/Shanghai 内容维护日期函数，保留未来日期拒绝规则，覆盖午夜、年末和闰日。没有回填旧日期或增加绕过开关。
2. **搜索检查读取旧结果。** 页面复用搜索窗口，旧查询结果在新查询防抖期间仍存在。原脚本只等“有结果”便读取，导致把上一组结果当作本次结果。检查先清空并等待旧结果移除，再输入新词；仍须找到并实际打开对应教程。
3. **检查中的旧文案。** 路由 smoke 仍期待“Next mission”，更新为实际的“Suggested next practice”，保留全部路由与目标链接检查。
4. **截图等待。** 两次捕获等待全页面动画超时，诊断记录有 pending 的 300ms 过渡。现在只等待当前截图区域内运行中的有限动画，并设明确期限；键盘、焦点、主题和几何断言不变。完整回归随后通过。
5. **格式工具运行环境。** 首次调用未传 Node 的 PATH，工具未运行；补足固定运行环境后执行。原失败日志保留。
