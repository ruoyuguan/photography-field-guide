## 读者问题与教学目标

新手拍完一组照片后，常见困难不是缺少评分，而是不知道怎样比较近似画面、为什么保留或舍弃一张，以及怎样把复盘变成下一次可执行的改动。

读者完成本批后应能：

- 把一小组照片按相似场景或信息角色分组，再比较候选，而不是无序逐张犹豫；
- 分开判断技术可用性与表达适配度，不把“最锐”或“最虚”当作普遍答案；
- 用可撤销的候选标记保留比较证据，不在第一轮仓促删除原片；
- 解释每张入选照片的理由，并确定下一次只改变的一个重要条件。

## 任务设计

英文任务名为 **Select, review, reshoot**，稳定 ID 为 `photo-review`，编号 04，版本 1，预计 20 分钟。教程路由为 `/learn/field-practice/photo-review/`，任务路由为 `/practice/photo-review/`，中文使用相同 slug 和 `/zh-cn/` 前缀。

### 1 · 预测

场景明确要求为一组照片选择候选，而不是评选艺术质量。正确答案 ID 为 `purpose-and-evidence`：比较画面是否符合拍摄意图，检查对焦、运动、曝光等技术问题是否妨碍这一用途，并用可撤销标记保留候选。

干扰项为 `sharpest-always-wins` 与 `delete-unselected`。解释同时排除两个极端：技术缺陷不能自动决定表达价值，表达偏好也不能抹去实际技术问题；未选照片在第一轮不等于无用文件。

### 2 · 本地筛选与复盘

只使用读者自己的本地照片查看器，不上传文件。任意 9–24 张同一次短拍摄即可；C1–C3 是可选来源，不是强制先修。

1. `group-similar-frames`：将近似画面或相同信息角色分组，保留原片，不在第一轮删除。
2. `compare-purpose-and-technique`：以一致的显示大小比较内容与构图，按需放大检查对焦、运动和高光；为每个预期角色保留少量候选，C3 可选择至多三张，但不硬凑配额。
3. `plan-next-experiment`：比较多于一张时的排列，指出一个信息或技术缺口，并为下一次拍摄选择一个具体改动。

### 3 · 自评

- `explain-selection`：能解释入选画面的作用，以及一张未选近似画面带来的信息。
- `review-technical-purpose`：能区分技术问题与编辑选择，并说明它们是否妨碍本次用途。
- `choose-next-change`：能提出下一次可观察、可执行的一项改变，而不是笼统写“拍得更好”。

完成仅表示读者标记完成，不表示照片通过评审或已经掌握摄影。
